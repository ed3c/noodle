# Stopped completed review

Initial-admission retirement cannot reject an already-admitted review. Use the
selected review inspect/reject operations and fresh next argv; do not restart scheduling
or forge a canonical event to get past that boundary.

The recovery uses the existing review reducer and projection/worktree owners.
Its intent retains the original snapshot/session bytes and a verified Git
bundle before cleanup. Local rejection is non-delivery; provider closure and
the outer supervisor checkpoint remain separately owned.

macOS may report `/private/var` for a spawn recorded under `/var`. Compare the
resolved existing directories for identity; do not weaken the common-directory,
branch/head, process-absence or dirty-worktree checks.

Worktree cleanup resolves an unprefixed branch before `noodle/<name>`. A stopped
caller must reject the competing alias rather than let that lookup delete a
different branch. Cleanup's warnings are not a receipt: read the exact path,
registration and branch back.

For a publication already verified merged by the Session, use publication
reconcile with the original claim/digest and confirmed merge commit. A merge
mailbox ack can precede an asynchronous merge failure; it is not completion.
Detached control roots need only verified ancestry, not another merge or a
branch switch. Recovery retains the failed attempt and separately cancels the
obsolete pending merge effect before recording original-order completion.

## Session readback

`review inspect` with only a workspace returns canonical facts and retained
source paths, including when configuration, Host, publication claim or original
request is unavailable. An explicit order/subject also attempts custody preflight
without obtaining the mutation lock. Failed preflight is a reported gap; it does
not hide data. No inspect branch repairs a projection or creates an intent.
`reject` alone acquires the existing lock and repeats all exact custody, absence,
archive and reducer checks. Readback remains available under an active lock;
this availability never authorizes a concurrent mutation.
