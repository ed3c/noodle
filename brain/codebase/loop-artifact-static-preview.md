# Loop artifact static preview

The loop graph's artifact `available` status only permits source-bound display. It is not an integrated acceptance receipt. The preview endpoint retains `acceptance: unknown` until the original Soodles owner supplies the exact task-envelope/candidate/head/acceptance-record binding; node status text cannot substitute for that evidence.

Static HTML preview uses registered artifact ID, SHA256 and graph version, then the existing ArtifactContent checks. HTML parsing rejects active/navigation/embedded elements and attributes; the display derivative prepends CSP and renders in an iframe with no sandbox privileges. Its document is not the original artifact bytes. Dynamic dimensional-drawing examples must be serialized to static SVG before delivery, instead of granting scripts or network to the preview.

Pele is a pinned renderer, not an owner. The bounded run projection retains unknown status and original node/artifact relations. The isolated CUA proof fixture uses a document golden-checked against the Go endpoint; it does not count as a real model-generated or accepted diagram.
